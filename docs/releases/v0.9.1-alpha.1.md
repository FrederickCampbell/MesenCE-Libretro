# MesenCE Libretro 0.9.1 Alpha 1

This release resets the project to an honest pre-1.0 alpha version and
consolidates the rapid experimental 1.x milestones into one tested baseline.

## Highlights

- Stable whole-object HD sprite priority across frames
- Geometry-based native 2x2 and 2x3 metasprite recognition
- OAM-permutation-independent signatures
- Original primary-OAM ownership preserved through scanline evaluation
- Immutable lifetime priority shared by every native member and synthetic addition
- Fixed mushroom/Koopa, mushroom/Goomba, reverse crossing, and multi-Koopa overlap
- Preserved audio, frame pacing, fast-forward, RetroAchievements memory, and save-state behavior
- Smooth repeating gameplay parallax and semantic HD-pack rules retained
- Repository version, changelog, documentation, and ignore rules normalized

## Tested renderer cases

- Native four-tile mushroom through Koopa
- Native four-tile mushroom through Goomba
- Koopa crossing mushroom in the opposite direction
- Three overlapping/crossing Koopas
- Synthetic Koopa additions
- Lone enemies and shells
- Item spawning
- screen-edge entry and exit
- pause during overlap
- fast-forward entry and exit
- state save/load
- HD packs disabled

No pack-side composite-anchor workaround is required.

## Alpha warning

This is an experimental Windows x64 release. Save-state compatibility is not
promised across alpha versions. Keep RetroArch's stock Mesen core installed
alongside this fork.

## Design philosophy

This alpha formalizes the fork's engineering boundaries: MesenCE remains the
hardware-emulation authority, RetroArch owns host pacing and synchronization,
and HD intelligence remains derived renderer state. The renderer now composes
recognized logical objects while preserving classic tile fallback and authentic
NES behavior underneath.

See [Design philosophy](../DESIGN_PHILOSOPHY.md).
