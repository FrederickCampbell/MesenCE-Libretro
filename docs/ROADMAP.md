## 1.0 criteria

- Stable NES/FDS non-HD behavior
- Stable classic and semantic HD packs
- No known whole-object overlap corruption
- No audio regressions during normal play, pause, fast-forward, rewind, or state load
- Clean Core Options presentation
- Reproducible Windows x64 release build
- Complete architecture, HD-pack, installation, and release documentation
