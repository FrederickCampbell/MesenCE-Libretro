# Changelog

## 0.9.1-alpha.1 - 2026-07-29

- Reset public versioning to a pre-1.0 alpha line.
- Added stable original-primary-OAM ownership for HD sprite candidates.
- Added geometry-based, OAM-order-independent native 2x2 and 2x3 metasprite detection.
- Added once-per-frame global temporal object matching.
- Added immutable lifetime priority tokens shared by native members and additions.
- Fixed whole-object overlap flashing and midpoint priority swaps.
- Confirmed native four-tile mushroom behavior without a pack-side ownership workaround.
- Preserved MesenCE v1.4 HD renderer stability where later local renderer changes had regressed.
- Retained semantic HD rules, gameplay parallax, RetroAchievements memory, audio transport, and frontend pacing.
- Consolidated project documentation and normalized repository ignore rules.

See [detailed release notes](docs/releases/v0.9.1-alpha.1.md).
